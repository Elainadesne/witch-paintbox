# 生图与出图 · 分支测试

测试分支：`codex/image-concurrency-auto-flow`。本次从 `main` 的 `8a72c9c` 开始，主分支不合并、不推送。

## 本次变化

- 新增「生图与出图」一级页面：自动配图、并发与队列、图片留存。
- 原「自动 AI 生图」改名为「回复后自动写 Tag」，原「自动点击生图」改名为「新标记自动出图」。两个开关全开时，正文及后处理完成后自动写 Tag，再生成图片；保持原有预设及请求内容。
- 共享图片队列支持 1～4 张同时生成，默认 1。覆盖手动配图、自动配图、重绘、试绘与角色图；单张失败不自动重试。并发限制作用于当前页面。
- 自动出图按原文顺序启动，保留 0～60 秒等待与补位间隔；切换聊天或关闭功能取消相关自动任务，不补跑历史标记。
- 旧开关、间隔和留存值继续有效；完整配置导出、导入及恢复默认包含新并发字段。旧文件未提供并发数时用 1。
- 生图设置和使用偏好分别恢复默认。队列状态和悬浮入口显示正在生成的图片数。

## 已验证

2026-11-04：TypeScript 构建及 14 项无网络调度测试通过。覆盖 FIFO、乱序完成补位、动态调高/调低并发、取消、失败隔离、不补跑历史、聊天切换、宿主忙碌/画幅保存等待，以及正文后处理结束后写 Tag 再并发出图的串联。

实际浏览器载入 `dist/index.js`，使用本机模拟酒馆宿主，验证：

- 设置保存与两个自动开关的流程提示。
- 两页独立恢复默认。
- 真实配置导出、解析和文件选择导入；旧文件默认值、无效值拒绝，以及导入后运行中队列上限同步。
- 1280 × 900 桌面和 390 × 844 手机布局；手机正文无横向溢出，六个导航入口可用；无页面运行异常。

运行调度测试：`npm test`（自动先构建）。浏览器测试需已有 Playwright，指定 `WITCH_PLAYWRIGHT` 为模块路径后运行 `node tests/workflow-browser.mjs`；截图默认放在 `/tmp/witch-image-workflow-preview/`。若本机 Node 环境开启了无效的环境代理，运行时设置 `NODE_USE_ENV_PROXY=0`。
