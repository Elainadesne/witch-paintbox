# 魔女画匣 · 更新预览

> 分支 `codex/tia-desktop-pet` → `main` · 2026-10-28 ～ 10-29

## ✦ 新功能

**NAI 氛围参考（Vibe Transfer）**
- 在「生图 API → NAI」页，画师工坊上方右侧新增「高级功能」，默认折叠，展开后是氛围参考。
- 可上传 PNG / JPEG / WebP，或导入 NAI 官网的 `.naiv4vibe` / `.naiv4vibeBundle`，也能导出合集。
- 每张图可单独启用，单独调参考强度和信息提取度。
- V4 / V4.5 的普通图片在第一次生图时编码，每张 2 Anlas；结果按「图片 + 模型 + 信息提取度」缓存，之后不再扣费；只改参考强度不需要重新编码。
- 导入的文件自带编码时直接使用，不扣费。
- V3 直接发原图。V5 官方尚未开放，面板提示并在生图时自动跳过。
- 最多 16 张；启用超过 4 张时提示每次生图的额外 Anlas。
- TauriTavern 中氛围图与编码缓存随「扩展数据」同步，换设备不用重新编码。

**Gemini 与 Grok 生图**
- 生图 API 顶部新增「更多画笔」纸条，展开后可选 Gemini、Grok；正在使用时纸条保持展开。
- Gemini 支持 Interactions、generateContent、OpenAI 兼容；Grok 支持 xAI 原生、OpenAI 兼容。
- 两者按「比例 + 分辨率」出图，AI 动态画幅自动换成对应比例。
- 四个通道各自保存连接、模型、画幅和画师配置；Gemini / Grok 的模型 API 预设首次使用时复制 GPT 预设。

**指定插图**
- 快捷菜单新增「指定插图」：按正文原文、文段（3 / 5 / 8 行）或句子点选，攒进配图清单后一次提交，每项一张。
- 清单支持单项移除、清空，切换选取方式保留，重叠范围不重复，手机上可折叠。
- 新增「不参与配图的标签」，默认 `think`、`thinking`、`UpdateVariable`，可自行添加；被排除的内容折叠显示，不会被选中配图。

**锚定角色负面提示词**
- 编辑角色时可添加专属负面词，随配置迁移和 TT 同步。
- NAI 单串合入全局负面词；多角色分栏只合入该角色那一栏。

## ✦ 界面重绘：「颜料未干」水彩纸

- 主面板换成毛边水彩纸：颜料井导航、手绘圈选中、晕开的颜料笔触按钮；手机导航改为底部颜料条。
- 取画菜单做成从画匣里抽出的便签，忙碌、出错、取消状态写在纸上；菜单贴着画匣、避开缇娅弹出。
- 引导、生图回顾空态、面板报错由缇娅出面提示，原始报错文字照常保留。
- 新增偏好「画匣色调」：跟随酒馆、日间、夜间；夜间为胡桃木纸。
- 打开面板缩短到 0.5 秒内；载入动画缩到 0.2–0.3 秒。开启「减少动态效果」时不播动画。

## ✦ 修复

- `@角色` 紧挨 `|` 或 `~` 时无法展开的问题已修复。
- 未保存的 `@角色`（如作品原有角色）不再报错，去掉 `@` 原样发送；要让 NAI 认出这类角色，需在提示词里写 Danbooru tag。已保存角色的未知服装、未知 `#通用服装` 仍会报错。
- 画幅协议条目兼容有无 📐 图标与全半角竖线；预设画幅协议开关与生图画幅双向联动。

## ⚠ 已知限制

- 旧版插件导入新版导出的配置可能报错，请先把各设备插件更新到同一版本再迁移。
- 普通酒馆中氛围图只保存在当前浏览器，不随配置文件迁移；TauriTavern 不受此限。
- Gemini / Grok 尚未用真实 Key 实测；直连 Google 官方接口可能被浏览器跨域限制（CORS）拦下。

更新后请在酒馆按 **Ctrl+F5** 强制刷新。
